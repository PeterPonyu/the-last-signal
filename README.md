# The Last Signal

An original golden fantasy browser adventure starring Zeyu, Dawnweaver and Sol.

[Play the game](https://peterponyu.github.io/the-last-signal/)

Free browser play, with no account or installation. Three connected maps offer defeat-driven story progression, two branching roads each, nine named keepers, twelve upgrade cards, eighteen enemy roles and three mobile Wardens. Normal and Hard both target a 15–20 minute successful journey. Hard offers denser encounters, larger defeat objectives and shorter warning windows. The cast uses 336 painted character frames, with distinct anticipation, impact, recovery and fallen poses. Painted scenery and 36 radiance frames give each battlefield its own atmosphere. Automatic combat powers are enabled by default and can be disabled in pause settings. Dawnweaver and Sol cast frequently, and ranged impacts show contact and damage.

Move with WASD or arrows. J or click swings Sunblade; Q releases Sunbreak; E pulses; Space dashes; F speaks, chooses a road or enters a gateway. Ranged light fires automatically. P or Escape pauses. Touch controls are included, and instructions can be hidden.

This repository contains the deployable game, including its JavaScript runtime source in app/ and content/. Serve the directory through any static HTTP server to play locally. Open index.html through HTTP rather than directly from the filesystem, because the game loads ES modules and an asset catalog.

The main character and companion are illustrated fictional adaptations. Character bodies, environment paintings and radiance atlases are original generated raster artwork. Clear danger outlines, interface symbols and lightweight particles are rendered in code. Reference photographs and private development records are not included. The original live score is synthesized in the browser and is off until enabled.

The game runs locally in the browser. Last results and instruction preferences use browser storage. Active journeys and cloud saves are not supported. The wider six-chapter story remains future content.
